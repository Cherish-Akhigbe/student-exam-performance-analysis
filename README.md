# Student Exam Performance Analysis

## Project Overview
This personal project investigates factors that may be associated with students' examination performance, with exam score as the target variable.

## Objectives
- Explore student performance data.
- Examine the relationship between study related factors and exam scores.
- Visualize patterns in the data.
- Apply statistical testing to investigate differences or relationships.

## Tools & Technologies
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- SciPy / statistical testing

## Project Workflow
1. Data cleaning and validation.
2. Exploratory data analysis.
3. Data visualization.
4. Statistical hypothesis testing.
5. Interpretation of findings.

## Key Learning Outcomes
The project strengthened my skills in data cleaning, exploratory analysis, visualization, and statistical reasoning.

## Project Type
Personal project.
